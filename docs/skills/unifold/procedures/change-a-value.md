# Change a value that others rely on

1. Run `unifold impact PATH`. It lists the users of the unit.
2. Run `unifold impact FILE` for each file you changed. Under `cited by` it lists every link to the file, with file and line.
3. Read each item of a `context.md` that cites the file, and correct what is no longer true.
4. Search the project for the old value, in every notation (15 minutes, 900 s).
5. [Finish](../SKILL.md#4-finish).
