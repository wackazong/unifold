# Invariants of emulator

What is true of the program at every moment. These lines keep the radio face indistinguishable from a sensor stick and a run reproducible.

- The radio face has nothing that the definition does not have: no extra characteristic, no marker in the advertising data.
- No randomness and no wall clock in anything that ends up in a reading.
- Radio timing stays real time and is not scaled with simulated time. The one exception is the time in which bonding is open: a central can measure it only by the tick count, so it follows simulated time.
