# Invariants of ui

What is true of the screens at every moment. These lines keep the screens dumb: they draw what they are given and judge nothing.

- A screen has no loading state for data that is on the phone. The need for a spinner means that the data is asked for in the wrong place.
- No screen compares a reading with a threshold to colour, sort or label anything. Only an alert makes a plant "need" something.
- No screen keeps data longer than the screen lives. It observes the query again instead.
