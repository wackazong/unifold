# Glossary of ui

Terms that have one fixed meaning inside this unit. Inherited terms are cited in [context.md](../explanation/context.md) and are not repeated here.

| Term | Meaning |
|---|---|
| Screen | One full view of the app with a name of its own, as listed in [screens](screens.md). |
| State | What a screen shows depending on the data it gets: filled, empty, aged and so on. Not the change state of a plant. |
| Mark | A short text next to a plant that tells its change state. |
| Bar | A strip across the top of every screen that reports a condition of the whole app. |
| Span | The stretch of time a chart covers: a day, a week or 90 days. |
| Preset | A named set of three lower limits that the owner can pick in the plant form ([presets.md](presets.md)). |
| Code | What one phone shows and another scans to join the same owner. |
| Prepared data | A fixed set of plants, readings and alerts against which a screen is built and tested: the cases of the [examples of `plant-data`](../../../docs/references/plant-data/index.md#examples). |
