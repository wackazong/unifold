## From slugline

### [slugline: the format of a slug](../../../docs/references/slug.md#format)

A slug has only `a-z`, `0-9` and one separator character: exactly one between two words, none at the start or the end. A slug may be empty. `slugify` and `slugify_with` return nothing else.
