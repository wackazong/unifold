# Context of core

### [slugline: the format of a slug](../../../docs/references/slug.md#format)
<!-- unifold:cites sha=b9ccc2dd -->

Says: a slug has only `a-z`, `0-9` and one separator character: exactly one
between two words, none at the start or the end. It may be empty.

Here: `slugify` and `slugify_with` return nothing else.
